# BioPulse / 生物科技情报库

**网站：[alex05250.github.io/biopulse](https://alex05250.github.io/biopulse/)**

从科研、产业、临床、政策到职业线索的可追溯索引。页面不需要账号，收藏只保存在当前浏览器。

## 国内应届求职与薪资证据（当前重点）

默认入口为**国内应届求职**，面向生命科学相关本科 / 硕士应届与初级岗位；按城市、学历原文、岗位方向、求职阶段、来源核验时间和薪资是否披露筛选。资深高管、博士后 / 高校序列、海外岗位不混入默认列表，未知经验要求也不凭“助理”名称猜成应届。

已原文核对万孚生物2027届、博拓生物2027届和康龙化成（绍兴）生产方向的企业公开简章（高校就业网托管）。**读过简章不等于确认当前空缺**；毕业窗口、截止日期、是否倒班、合同及实习 / 转正条件保留原文或明确缺失。

“薪资证据与比较”将单岗位报价、招聘批次整体参考、招聘机构报告参考分开。整批综合年薪不代填到每个岗位；不猜税口径、周期、发薪月数或到手收入。只有同城市、岗位方向、学历集合、校招 / 初级、雇主类型、币种、周期、税口径、基本工资 / 总包与发薪月数一致，且至少5个岗位、3家企业时，才显示报价上下限分别计算的中位数。这是保守展示门槛，**不是行业代表性保证**；当前应届单岗数字报价仍不足，不用高管报价填补。

收藏中国岗位时可建立当前浏览器的字段基线，下次打开比较薪资、学历、地区、状态等变化；已有收藏需点击建立基线。**不是后台提醒，也不跨设备同步。** CSV包含核验级别、口径缺失和空缺是否确认。

已知招聘PDF由云端每日做存续与SHA-256变化检查（`config/career_sources.json`、`data/document_status.json`）；文件改变时需重读，不把检查文件是否可读称为新岗位发现或招聘有效核验。本机20:30整理继续负责发现与原文阅读，优先本科 / 硕士及初级岗位。详见 [求职与薪资方法](docs/CAREER_METHOD.md)。

## 已实现

- GitHub Actions 每日北京时间 **08:17** 采集公开 API / RSS，构建并发布 GitHub Pages。
- 按 DOI、NCT 编号、官方职位 ID 等稳定标识去重，保留首次发现和最近核对时间。
- 比较分期、登记状态、预印本版本、公开薪资等可见字段；保留差异，不虚构历史变化。
- 中英检索、分类 / 节点 / 类型 / 日期筛选、排序、收藏、记录详情与 CSV 导出。
- 每日增量、带出处的 AI 中文精选、可解释的主题网络。
- SQLite、JSON、Markdown 双链三种可移植格式。
- 自适应明暗主题，移动端导航，键盘与减少动态效果偏好支持。

## 覆盖不是全量

自动源与目录源在 `data/sources.json` 中分开配置；实时结果见网页“信源与采集状态”。有 16 个云端采集配置，另有中国公开信源的本机定时核验补充，部分来源可能被限制。不得把目录源数称为“已接入信源数”。

| 类型 | 当前自动采集范围 | 主要限制 |
| --- | --- | --- |
| 科研 | Europe PMC / PubMed 题录、Nature Methods RSS、bioRxiv 两个分类 | Europe PMC 35天分页、每检索预算1000条；预印本7天、分类90个版本；不是全领域全量 |
| 临床 | ClinicalTrials.gov 指定关键词及已入库NCT编号 | 35天分页、预算1000条，并按NCT额外复查旧记录；登记不是审批或疗效结论 |
| 产业 | GEN、STAT Biotech、Fierce RSS | 只索引公开标题；原站可能付费、限流或拒绝访问 |
| 政策 | FDA Biologics RSS（能否成功以状态页为准） | 国内政策通过有原文核对的定时编辑补充，不称为全自动监控 |
| 岗位 | 云端：两家海外官方招聘与三份已知国内PDF存续检查；本机核验：国内企业校招简章、公开岗位与高校岗位 | PDF检查不等于新岗位发现；区分应届、资深、海外和高校序列；样本不是行业均值或到手收入 |

公众号已加入公开检索清单，但遇验证码或无法确认账号/日期时只收录未核验线索。国内岗位与发布者官网薪酬解读已补入公开样本；仍是本机定时核验，不是云端全量抓取。Insight 官方接口文档已核验，实际 API 授权、凭据、额度与公开再分发范围尚未落实，不宣称已接通专业库。详见 [中国信源实测与边界](docs/CN_SOURCE_ACCESS.md)。不把匿名爆料当事实，不抓临床联系人、求职者或付费全文。

首日“新增”表示首次建库，不是当日新发生的突破。部分文献的日期来自索引，可能是期刊标注日期而不是网络首次出现时间。

## 当前执行范围

本阶段按用户选择**只补公开信息**，不购买、不申请试用或付费接口。专业库仅保留目录，不作为更新阻塞，也不反复请求订阅。公开产业资讯与同一厂商的付费专业数据分开处理。

## 两层定时

1. **GitHub 云端**：每日 08:17 采集、入库、发布；网页关闭和本机离线不影响该层。GitHub 计划任务可能延迟，并有平台运行限制。长期失败应查看 Actions，不能用原定时间代替实际成功时间。
2. **本聊天的 AI 整理**：每日 20:30 检查云端结果，并按公开原始来源补充中文精选、国内政策与职业线索。依赖本机 Codex 可运行；没有完成的日期显示“自动索引汇总”，不会伪装成已完成 AI 审查。

不需要额外 AI API 密钥。GitHub Pages 是静态网站，不直接在网页上写数据库。AI 整理执行方法见 [RUNBOOK.md](RUNBOOK.md)。

## 本地运行

需要 Python 3.11+（仅标准库）和用于语法检查的 Node.js。

```powershell
python -m unittest discover -s tests -v
python scripts/collect.py
python scripts/build.py
python -m http.server 8786 --bind 127.0.0.1
```

浏览器打开 `http://127.0.0.1:8786/`。仅更新编辑记录时运行 `python scripts/collect.py --offline`，不会触发全网采集。

## 数据文件

- `data/items.json`：结构化索引；不含文章全文。
- `data/history.json`：每次首次入库与字段差异。
- `data/status.json`：逐源采集、定时核验、验证墙与失败状态。
- `data/access.json`：中国信源的核验时间、实际覆盖和权限缺口。
- `config/cn_watchlist.json`：本机定时补充的公开检索与核验清单。
- `data/curated.json`：经过原文核验的人工 / AI 补充记录。
- `data/editorial.json`：中文标题、解读与每日精选，独立于机器题录。
- `data/library.sqlite`：记录、来源、节点、提及关系、历史、简报与全文检索索引。
- `knowledge/`：可作为 Obsidian 库打开的 Markdown 节点与记录。

英文 FTS 索引使用 SQLite `unicode61`；中文检索以网页的字符串包含匹配为主，不宣称中文分词检索。
