# 国内应届求职与薪资方法

## 服务对象

生命科学相关本科 / 硕士应届与初级岗位。默认只显示有原文依据的 `audience=campus/junior`，未知经验要求不推定为初级。高校助理教授不能因“助理”二字进应届列表；企业校招中的“经理”若原文明示应届，则保留校招判断并注明依据。

## 本次证据

2026-11-16读取中科院生物与化学交叉研究中心官网完整招聘JD（原站发布日期2026-10-21），新增1条科研助理单岗位基础月薪8000–12000元的记录。税口径、发薪月数及是否仍有空缺未确认；未明确应届适用性，故为 `audience=unknown`，不计入默认应届报价或统计。本科放宽需相关经验；“至少工作一年”为拟任工作时长要求，不误填为已有一年工作经验。完整JD阅读也不覆盖显式的 `VACANCY_UNCONFIRMED`。

2026-11-15完整阅读并目视核对表格：

- 万孚生物2027届企业原版简章，暨南大学就业网托管；相关专业的本科 / 硕士职位独立建档，不按岗位需求人数推算市场需求。
- 博拓生物2027届企业原版简章，杭州电子科技大学就业网托管。第4页岗位、第5页薪资整体范围分别阅读；合并单元格已目视核对。不将跨岗位合计招聘人数分配到每条记录。
- 康龙化成（绍兴）生产方向企业简章，重庆化工职业学院就业网托管。生产技术员明确接受2026 / 2027届专科本科；生产管培生只列硕士及相关经验优先，未明确校招批次，因此单列为经验待核验，不进默认应届列表。

可追溯URL、页码、读取时间、核验范围写在记录中；源文件SHA-256在 `config/career_sources.json`。源文件和全文只保留在忽略的本地工作目录，不复制到公开站点。大学就业网站托管原版简章不是“雇主官网已确认当前招聘”，未登录网申、未确认当前空缺。

## 薪资分层

1. 单岗位招聘报价：数值、币种、周期、税口径、基本工资 / 综合总包、发薪月数逐字段保存，缺失不猜。
2. 整批校招参考：单独为 `salary_scope=campaign` 记录。博拓7–15万元是整批校招综合年薪，已包含月度工资、综合补贴与年终奖；未细分学历或岗位，未写明税口径，不能代填给多个岗位。
3. 招聘机构 / 行业报告：与具体岗位分开；保留统计期间、样本与适用范围，未知字段不转换。不得拿报告或匿名爆料填补单岗工资。
4. Offer与实际收入：当前没有此类证据。不称“真实到手工资”。

同城市、方向、学历集合、应届 / 初级、雇主类型、币种、周期、税口径、基本工资 / 总包、发薪月数才能分为一组。最低5岗位且3雇主才显示报价上下限分别计算的中位数；少量样本仍不具有行业代表性。未明确税口径、单边报价、异常区间、过期、仅静态简章或雇主未具名的记录不进入当前可比组。未知薪数的月薪不按12薪或13薪年化，年薪不当成保证月薪。

## 有效期与持续核验

- `verified_at` 是实际阅读原文的时间；重新导入不刷新。`last_collection_at` 是最近实际云端采集时间，与网页构建时间分开。
- 近30天核对过原文不等于仍招。没有截止日期不认定永久有效；只把原文明示日期用于过期判断。
- 云端 `check_documents.py` 只检查已知PDF可读性及哈希。变化或失败保留旧数据并提示需要复核；不把未变的旧简章更新成“今日新招”。新增发现、重新阅读仍依赖本机20:30公开整理。
- 本地收藏追踪需用户建立基线。下次打开比较字段，不发送后台提醒，不跨设备同步，也不保证抓到了所有变化。

## 保留的缺口

当前应届样本仍集中于少数企业和城市，单岗位数字报价不足。不能给“全国生物本科起薪”“行业平均薪资”或薪资趋势。后续核验应优先补不同地区、不同企业的真实单岗报价，而不是堆同一雇主的职位数。
