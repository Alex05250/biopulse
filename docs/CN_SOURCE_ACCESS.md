# 中国信源的实际接入范围

这次核查把三件不同的事分开：公开文章发现、专业库授权调用、国内招聘与薪酬口径。结果不是“已经全量接入”。逐项核验时间见网站信源页和记录详情。

## 公众号：可以发现公开文章，但不等于完整订阅

已加入 `config/cn_watchlist.json` 的定时公开检索。第一次测试的 BioArt 相关链接在微信原站进入了滑块验证，所以只按**未核验线索**保留标题和链接；没有读取正文，也没有确认发布账号、发表时间或讲座/研究内容。验证链接中的临时令牌不保存、不公开。

不会自动处理验证码，也不从第三方转载、缓存绕开验证。用户可自行在浏览器完成验证，再继续核验。原始论文可作为独立研究来源追踪，但不能据此假称读过公众号解读。Bing RSS 的试验返回了大量不相关内容，因此没有接入生产采集。

## 专业数据库：官方接口存在，权限仍需确认

[Insight 官方开放平台](https://db.dxy.cn/v5/home/open)及其[接口文档](https://db.dxy.cn/v5/home/document)已实际阅读。文档列出了全球管线、临床、新闻、交易、融资等接口，调用需要平台发放的 App ID 与 SecretKey 等签名凭据。**当前没有调用授权，也没有完成真实数据联调。**

普通网页订阅、API/MCP 授权、调用额度、可导出字段和公开再分发范围不是同一个问题。医药魔方、药智、摩熵等需分别向厂商确认，不能拿一个平台的接口说明推断其他平台都已接通。

不要在聊天或 GitHub 提交密码、接口密钥或授权导出文件。将来获得专业数据授权时应先进入单独的私有存储，确认允许公开的字段和使用范围后再设计发布方案。本项目公开构建会拒绝 `mode=paid` 来源的记录及标为 private 的记录，避免误发布。

## 国内薪资：先补公开报价与正式发布者，不冒充真实收入

已读取[南方科技大学教师官方招聘页](https://faculty.sustech.edu.cn/?cat=11&go=2&iscss=1&snapid=1&tagid=zhangxm)，补入研究助理教授、研究副教授和博士后三个样本。固定税前年薪、综合年薪、已包含的补助及有条件奖励分别记录，不重复叠加。页面未明确完整发布日期，因此不包装成今日新招。

已读取 [Michael Page 中国生命科学职位公开列表](https://www.michaelpage.com.cn/jobs/%E7%94%9F%E5%91%BD%E7%A7%91%E5%AD%A6/healthcare-pharmaceutical)，核对前12条列表信息并选择5条中国岗位。其中4条有人民币年薪报价，1条未公开薪资。没有把国际地区岗位因人民币计价误标为国内，也没有把一条跨度15倍、需要二次确认的区间纳入可比薪酬样本。未逐一读取全部64个岗位的完整JD。

已读取[科锐国际关于2026指南的公开解读](https://www.careerintlinc.com/report/3168.html)。摘要中的参考区间没有明确周期和税口径，所以保留这些缺口，不擅自换算为年薪；没有宣称获取完整报告。

样本偏向资深管理/专家与高校研究岗位，不能估计应届生行情、全国行业均值或真实到手收入。实际收入仍需具体 offer、合同、奖金兑现与税费等证据；匿名爆料只作线索。

## 定时机制

公开API/RSS仍由 GitHub 每天08:17运行。中国官网、公开岗位、报告和公众号线索由本机 Codex 每天20:30按 watchlist 发现并核验，依赖本机可运行，不保证在电脑离线时更新。没有可读原文或账号权限的，保留限制而不是宣称采集成功。
